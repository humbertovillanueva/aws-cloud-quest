# AWS Cloud Quest

An interactive browser-based study game for reviewing AWS Certified Cloud Practitioner concepts.

The challenge contains 50 questions across cloud economics, security, compute, storage, networking, databases, monitoring, messaging, and the AWS Well-Architected Framework. Questions are shuffled for each run, answers receive immediate feedback, and the final screen summarizes the score and best streak.

## Highlights

- 50 multiple-choice questions
- Randomized question and answer order
- Immediate correct-answer feedback
- Live score, streak, and progress tracking
- Final rank based on total score
- Responsive, dependency-free interface

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/humbertovillanueva/aws-cloud-quest..git
cd aws-cloud-quest.
open index.html
```

## Built with

- Semantic HTML
- Modern CSS
- Vanilla JavaScript

## About the project

I built AWS Cloud Quest as a more active way to review cloud concepts than rereading notes. Turning the material into a scored game made it easier to identify weak areas and repeat the complete review.
